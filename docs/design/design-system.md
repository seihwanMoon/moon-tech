# moon's tech 디자인 시스템

기준 이미지:

- `docs/design/moons-tech-home-concept.png`
- `docs/design/moons-tech-source-note-concept.png`

## 방향

`moon's tech`는 화려한 제품 랜딩 페이지보다 기술 출판물에 가까운 인상을 사용한다. 넓은 여백, 강한 한글 제목, 얇은 구분선, 청색과 청록색의 제한된 강조를 통해 AI·제조·코딩이 하나의 시스템으로 연결된다는 이미지를 만든다.

| --------- | --------- | --------- |
| 배경      | `#F8FAFD` | `#111722` |

| 본문      | `#12213F` | `#F2F6FC` |

배경은 따뜻한 베이지가 아니라 차가운 near-white다. 장식용 그라디언트, 네온, 광택 효과를 사용하지 않는다.

## 타이포그래피

- 제목·본문·UI: `Noto Sans KR`, system sans-serif
- 코드·타임스탬프: `IBM Plex Mono`, monospace
- 홈 H1: desktop `clamp(2.8rem, 5vw, 5rem)`, 굵기 760, 줄높이 1.18
- 글 H1: `clamp(2rem, 4vw, 3.5rem)`, 굵기 740
- H2: `clamp(1.45rem, 2.5vw, 2rem)`
- 본문: 1rem, 줄높이 1.75~1.82
- 작은 UI 글자: 0.82~0.9rem, 브라우저 기본값에 맡기지 않는다.

## 간격과 컨테이너

- 기본 간격 단위: 4px
- 콘텐츠 리듬: 8, 12, 16, 24, 32, 48, 72, 96px
- 홈 최대 폭: 1,280px
- 일반 글 최대 폭: Quartz 기본값 유지
- Source Note 핵심 최대 폭: 1,050px
- Source Note 내부: desktop 26% / 74%, tablet 30% / 70%, mobile 1단
- 본문 최소 좌우 여백: desktop 32px, mobile 20px

## 컨테이너 규칙

- 목록과 콘텐츠는 열린 레이아웃과 얇은 수평선을 우선한다.
- 모든 섹션을 카드로 감싸지 않는다.
- 카드가 필요한 프로젝트와 서비스 영역만 1px 경계선, 최대 10px radius, 매우 약한 그림자를 사용한다.
- Source Note의 주장과 해석은 동일한 크기와 구조를 사용하되 라벨과 경계색으로 구분한다.
- 색상만으로 의미를 전달하지 않는다.

## 홈 화면

- 헤더: 텍스트 워드마크, 핵심 탐색, 검색, 다크 모드만 표시한다.
- 첫 화면: 별도 eyebrow 없이 핵심 문장과 짧은 설명, “최신 글 보기” 링크를 둔다.
- AI·제조·코딩: 세로 구분선을 가진 열린 3열 rail을 사용한다.
- 최근 글: 카드 대신 제목·날짜·화살표가 있는 목록을 사용한다.
- 프로젝트: 하나의 대표 프레임으로 강조한다.
- 서비스: “함께 해결할 수 있는 문제”를 문제 정의→데이터·분석→시스템 구축→운영·개선 흐름으로 보여준다.

## Source Note

- Explorer는 유지한다.
- 메타데이터 열과 핵심 요약 열 사이에 얇은 세로선을 둔다.
- 유형 강조색은 상단선과 텍스트 라벨에 제한한다.
- 핵심 포인트는 번호, 제목, 요약, 위치를 같은 행에 배치한다.
- 출처 바는 요약 하단에 항상 노출한다.
- 상세 callout은 한 덩어리 accordion처럼 이어지는 얇은 행으로 표현한다.
- 오른쪽 TOC, Graph, Backlinks는 숨긴다.

## 상호작용과 접근성

- 링크와 버튼은 명확한 `:focus-visible` 외곽선을 갖는다.
- 터치 대상 최소 높이는 44px다.
- `prefers-reduced-motion`에서는 전환과 애니메이션을 제거한다.
- 모바일에서 긴 URL을 그대로 노출하지 않는다.
- 인쇄에서는 Explorer, 헤더, 검색, 화면 전용 컨트롤을 숨기고 모든 상세 callout을 펼친다.

## 허용된 첫 화면 문구

- `moon's tech`
- `AI`, `제조`, `코딩`, `프로젝트`, `서비스`, `소개`
- `기술을 이해하고, 현장에 적용하고, 작동하는 시스템으로 만듭니다`
- `AI, 제조 데이터, 코딩 도구를 탐구하며 실무에 적용 가능한 방식으로 정리합니다.`
- `최신 글 보기`

이 목록 밖의 badge, pill, 통계, 보조 kicker를 첫 화면에 추가하지 않는다.
